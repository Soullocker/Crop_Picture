# 科研图片裁剪 APP（V2.1.0）

这是 `Crop Picture` 的图形界面版本，面向科研绘图场景，用来批量裁剪图片白边、透明边和浅色背景边距。

## 主要功能

- 选择单张图片或整个文件夹
- 裁剪后可保存到其他文件夹
- 也可以直接保存到原文件夹，并自动加上 `裁剪_` 前缀，避免覆盖原图
- 支持批量处理，单张失败不会中断后续图片
- 支持重复裁剪提醒，避免反复处理同一批文件

## 支持格式

`.png`、`.jpg`、`.jpeg`、`.bmp`、`.tif`、`.tiff`、`.webp`、`.gif`、`.ppm`、`.pgm`、`.pbm`、`.pnm`、`.svg`

## 运行方式

在项目根目录双击：

```text
tools\run_app.bat
```

也可以直接运行：

```text
.\.venv\Scripts\python.exe .\app\main.py
```

## 打包方式

在项目根目录运行：

```text
tools\build_app.bat
```

打包完成后，独立程序会生成在 `dist/` 目录中。

## 使用建议

- 科研绘图、论文插图、白底图、透明底图、纯色背景图都比较适合
- 如果是 `SVG`，请确保电脑上有 `Microsoft Edge` 或 `Google Chrome`
- 如果裁剪太紧，可以适当增大保留边距
