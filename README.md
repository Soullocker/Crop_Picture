# Crop Picture 图片裁剪 APP

当前版本：`v2.2.0`

这是面向科研绘图场景的 Windows 图片裁剪 APP，用于去除论文插图、图表和示意图的白边、透明边及浅色背景边距。

## 主要功能

- 一个“选择图片或文件夹”入口：未选图片时选择当前文件夹，选中一张或多张时仅处理所选图片。保留 Windows 原生浏览、搜索和缩略图界面。
- 文件夹批量处理不递归进入子文件夹；图片可按住 Ctrl 或 Shift 多选。
- 批量处理跳过以 `裁剪_` 开头的图片，避免重复裁剪已有结果；单独选择的图片仍可处理。
- 输出到原文件夹时自动添加 `裁剪_` 前缀，保留原图；重新裁剪原图会覆盖更新同名结果。
- 裁剪前后并排预览；文件夹输入可选择其中任意原图。预览使用当前参数，不创建输出文件。
- 正式处理后可查看已经保存的实际输出，避免将参数预览误认为最终文件。
- 支持取消预览或裁剪，保留已经完成的输出；关闭窗口时会先安全停止后台任务。
- 无需裁剪的位图和 SVG 直接复制原文件，完整保留文件内容和元数据，不重新编码。
- 自动记住参数和输入、输出路径。
- 重复裁剪记录跨软件重启保留；原图、参数或输出位置变化后允许重新处理，输出被删除后也可重新生成。
- 单张图片失败时跳过并记录原因，后续图片继续处理；失败或取消任务不记录为整批成功。

## 支持格式

`.png`、`.jpg`、`.jpeg`、`.bmp`、`.tif`、`.tiff`、`.webp`、`.gif`、`.ppm`、`.pgm`、`.pbm`、`.pnm`、`.svg`

动画 GIF 和多页 TIFF 暂不支持，程序会提示原因。

SVG 通过 Microsoft Edge 或 Google Chrome 临时渲染检测边界，最终仍保存为 SVG 矢量文件；SVG 预览显示检测图。

## 源码运行

首次使用时双击 `tools\install_dependencies.bat` 安装依赖，然后双击：

```text
tools\run_app.bat
```

也可以在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe .\app\main.py
```

源码运行需要 Python 3.12 或更高版本，以及 `requirements.txt` 中的依赖。

## 使用步骤

1. 点击“选择图片或文件夹”，进入目标目录。不选择图片时，右下角显示“选择该文件夹”；选中一张或多张图片后，显示“处理所选图片”。前者批量处理目录中的原图，后者仅处理所选图片。
2. 设置输出文件夹，或勾选“输出到原文件夹”。
3. 在预览列表中选择图片，点击“预览裁剪”。
4. 调整参数并重新预览，满意后点击“开始裁剪”。
5. 需要停止时点击“取消任务”；已经完成的结果会保留。

参数说明：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 保留边距 | 5 | 检测到内容后额外留下的像素边距 |
| 背景容差 | 12 | 背景与内容的颜色差异阈值；浅色内容被误裁时可减小 |
| 透明判断阈值 | 8 | 不大于此透明度的像素视为空白 |
| SVG 检测尺寸 | 2400 | SVG 检测图最长边的大致像素数，越大越细但越慢 |

设置和裁剪记录保存在当前 Windows 用户的配置中，源码和打包程序共用，不写入图片文件夹。

## 打包

双击：

```text
tools\build_app.bat
```

独立程序生成在 `dist/Crop_Picture.exe`，使用时不需要另行安装 Python。

打包脚本会隔离其他软件的 DLL 搜索目录，避免把同名但不兼容的 DLL 打入程序。打包后会实际启动 EXE 进行无窗口自检，检查 Qt 加载和界面初始化；启动失败不会报告打包成功。

## 验证

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
